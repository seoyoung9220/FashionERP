## 지켜야 할 것

- CSV는 **UTF-8**, 첫 행은 헤더, 열 이름은 `dictionary.md`와 **정확히 일치**
- 열 이름 매핑 UI를 만들지 않으므로 **이 열 이름이 곧 계약**입니다
- 🔴 **불량률 분모는 `inspected_qty`(검수 수량)로 통일**합니다
- 🔴 기존 주문 CSV에 **UTF-8 BOM**이 있습니다. 추가 파일은 BOM 없이 저장하고, 적재는 어느 쪽이든 `utf-8-sig`로 읽습니다
- ID는 문자열 (`P001` — 엑셀에서 `001`이 `1`로 깨지지 않게 주의)
- 열거형은 `enums.json`의 영문 코드로 작성. 한글 라벨을 CSV에 넣지 않습니다
- 불리언은 `TRUE` / `FALSE` 대문자
- **주문 1건 = 1장**으로 간주합니다. 주문 데이터에 수량 열이 없기 때문입니다
