## 샘플 데이터 구성

| 항목 | 규모 | 반드시 포함할 것 |
|---|---|---|
| 상품 | 6~8종 | 팬츠·니트·셔츠 등. 리드타임·MOQ가 서로 다르게 |
| 거래처 | 2~3곳 | — |
| 발주·입고 | 12~15건 | **1건은 불량률이 이전 건 평균의 2배 이상** |
| 판매 | 최근 30일 | 상품별 판매 속도가 다르게 |
| 반품 | 40~60건 | **한 상품에 `사이즈·핏` 의견이 반복**되도록 `review_text` 작성 |
| 비용 | 상품별 | 적어도 **1개 상품은 기여이익이 음수**, **1개는 비용 항목 누락** |

시연 시나리오가 이 데이터 위에서 돌아갑니다 — 불량률 급증 발견 → 재고 소진 임박 → 불량률 반영 발주량 → AI 반품 분석 → 수익성 확인 → 조치 등록.

> 실제 고객 개인정보를 쓰지 않습니다. `review_text`는 직접 작성한 가상 문장입니다.

## 계산 검증 기대값 (2:00)

샘플 데이터에 대한 **수작업 기대값**을 `expected/expected-metrics.md`에 작성합니다.
통합 단계(5:00)에서 백엔드 계산 결과와 대조합니다. 상품 2~3개만으로 충분합니다.

| 지표 | 대조 대상 |
|---|---|
| 불량률 | 발주 건 2건 + 거래처 1곳 |
| 현재 재고 | 상품 2개 |
| 권장 발주량 | 상품 2개 (MOQ 올림이 적용되는 것 1개 포함) |
| 기여이익 | 상품 2개 (음수 1개 포함) |
| 반품률 | 상품 1개 |

## 지켜야 할 것

- CSV는 **UTF-8**, 첫 행은 헤더, 열 이름은 `dictionary.md`와 **정확히 일치**
- 열 이름 매핑 UI를 만들지 않으므로 **이 열 이름이 곧 계약**입니다
- 🔴 **불량률 분모는 `inspected_qty`(검수 수량)로 통일**합니다
- ID는 문자열 (`P001` — 엑셀에서 `001`이 `1`로 깨지지 않게 주의)
- 열거형은 `enums.json`의 영문 코드로 작성. 한글 라벨을 CSV에 넣지 않습니다
- 불리언은 `TRUE` / `FALSE` 대문자
